# Official wallet logos

Place only original or officially supplied wallet logos in this folder.

## Preferred format

1. SVG with a transparent background.
2. Otherwise PNG with a transparent background, preferably at least 512×512 px.
3. Keep the original brand colours; OTT adds the surrounding card treatment.
4. Do not add a white square, screenshot background, shadow or extra text.

## Exact filenames

```txt
xaman.svg
crossmark.svg
gemwallet.svg
walletconnect.svg
joey-wallet.svg
katz-wallet.svg
metamask-xrpl.svg
ledger.svg
```

PNG is also accepted by using the same name with `.png` instead of `.svg`.

Use lowercase letters, no spaces and no version numbers in filenames.
