# Official DeFi and ecosystem logos

Place only original or officially supplied project logos in this folder.

## Preferred format

1. SVG with a transparent background.
2. Otherwise PNG with a transparent background, preferably at least 512×512 px.
3. Keep the original project colours and proportions.
4. Do not add screenshots, backgrounds, promotional slogans or unofficial redesigns.

## Exact filenames

The filename matches the project `id` in `src/lib/defiDirectory.ts`:

PNG is also accepted by using the same name with `.png` instead of `.svg`.

Research-stage entries may receive a logo, but the logo never changes their evidence or verification status.
